0. PREREQUISITES & COMMANDS
================================================================================

--- Start PostgreSQL (if not running) ---
  # Windows service
  net start postgresql-x64-18

--- Create database (first time only) ---
  psql -U postgres -c "CREATE DATABASE wasac_db;"

--- Build & run the app ---
  cd C:\Users\RCA_USER_23\Pictures\Screenshots\wasac
  mvn clean package -DskipTests
  mvn spring-boot:run

  # Or run the JAR:
  java -jar target\wasac-0.0.1-SNAPSHOT.jar

--- Health check (no token) ---
  curl http://localhost:8080/actuator/health

--- Swagger auth ---
  1. POST /api/auth/login → copy "token" from response
  2. Swagger → Authorize → paste: Bearer <token>

--- curl with JWT (replace <TOKEN>) ---
  curl -H "Authorization: Bearer <TOKEN>" http://localhost:8080/api/customers

--- PowerShell with JWT ---
  $h = @{ Authorization = "Bearer <TOKEN>" }
  Invoke-RestMethod -Uri "http://localhost:8080/api/customers" -Headers $h

--- OTP from database (signup / forgot-password testing) ---
  psql -U postgres -d wasac_db -c "SELECT email, otp_code, purpose, expires_at FROM otp_verifications ORDER BY id DESC LIMIT 5;"

--- View recent bills ---
  psql -U postgres -d wasac_db -c "SELECT id, bill_reference, status, total_amount, due_date FROM bills ORDER BY id;"

--- View triggers (installed on startup by DatabaseRoutineInitializer) ---
  psql -U postgres -d wasac_db -c "SELECT trigger_name, event_object_table, action_timing, event_manipulation FROM information_schema.triggers WHERE trigger_schema = 'public' ORDER BY event_object_table, trigger_name;"

--- View trigger functions ---
  psql -U postgres -d wasac_db -c "SELECT proname AS function_name FROM pg_proc JOIN pg_namespace n ON n.oid = pg_proc.pronamespace WHERE n.nspname = 'public' AND proname LIKE 'fn_%' ORDER BY proname;"

--- View stored procedures ---
  psql -U postgres -d wasac_db -c "SELECT proname AS procedure_name FROM pg_proc JOIN pg_namespace n ON n.oid = pg_proc.pronamespace WHERE n.nspname = 'public' AND prokind = 'p' ORDER BY proname;"

--- View trigger + procedure inventory (one query) ---
  psql -U postgres -d wasac_db -c "SELECT 'trigger' AS type, trigger_name AS name FROM information_schema.triggers WHERE trigger_schema = 'public' UNION ALL SELECT 'procedure', proname FROM pg_proc JOIN pg_namespace n ON n.oid = pg_proc.pronamespace WHERE n.nspname = 'public' AND prokind = 'p' ORDER BY type, name;"

--- View source code of a trigger function (example: bill insert) ---
  psql -U postgres -d wasac_db -c "SELECT pg_get_functiondef(oid) FROM pg_proc WHERE proname = 'fn_notify_on_bill_insert';"

--- View source code of a procedure (example: late penalty) ---
  psql -U postgres -d wasac_db -c "SELECT pg_get_functiondef(oid) FROM pg_proc WHERE proname = 'sp_apply_late_penalty';"

--- View notifications created by DB triggers ---
  psql -U postgres -d wasac_db -c "SELECT id, customer_id, event_type, message, email_sent, created_at FROM notifications ORDER BY id DESC LIMIT 10;"

--- Test cursor procedure manually (overdue bill reminders) ---
  psql -U postgres -d wasac_db -c "CALL sp_notify_overdue_bills();"

Expected triggers:
  trg_bill_insert_notification      → AFTER INSERT on bills
  trg_payment_full_notification     → AFTER INSERT on payments

Expected functions:
  fn_bill_notification_message, fn_notify_on_bill_insert, fn_handle_full_payment

Expected procedures:
  sp_record_payment, sp_apply_late_penalty, sp_notify_overdue_bills (uses CURSOR)

If missing, restart the Spring Boot app and check logs for:
  PostgreSQL billing routines installed successfully

13. LATE-PAYMENT PENALTY CRON (automatic — no admin API)
================================================================================
Runs daily at 02:00 (configurable). No Swagger endpoint.

application.properties:
  app.billing.penalty-days-overdue=30
  app.scheduler.cron.penalties=0 0 2 * * *

To test quickly, temporarily set cron to every 2 minutes:
  app.scheduler.cron.penalties=0 */2 * * * *
Restart app. Bills UNPAID/APPROVED/PARTIALLY_PAID with dueDate > 30 days ago
get penalty applied + late-payment warning email.

Simulate overdue bill in DB (dev only):
  psql -U postgres -d wasac_db -c "UPDATE bills SET due_date = '2026-01-01' WHERE id = <ELECTRIC_BILL_ID>;"

Manual penalty (FINANCE/ADMIN token):
POST /api/bills/<BILL_ID>/apply-penalty

13A. DATABASE TRIGGERS & PROCEDURES — VERIFY IN PostgreSQL
================================================================================
Connect interactively:
  psql -U postgres -d wasac_db

List all triggers:
  SELECT trigger_name, event_object_table, action_timing, event_manipulation
  FROM information_schema.triggers
  WHERE trigger_schema = 'public'
  ORDER BY event_object_table, trigger_name;

List trigger functions:
  SELECT proname FROM pg_proc
  JOIN pg_namespace n ON n.oid = pg_proc.pronamespace
  WHERE n.nspname = 'public' AND proname LIKE 'fn_%';

List stored procedures:
  SELECT proname FROM pg_proc
  JOIN pg_namespace n ON n.oid = pg_proc.pronamespace
  WHERE n.nspname = 'public' AND prokind = 'p';

View function/procedure source:
  SELECT pg_get_functiondef(oid) FROM pg_proc WHERE proname = 'fn_notify_on_bill_insert';
  SELECT pg_get_functiondef(oid) FROM pg_proc WHERE proname = 'fn_handle_full_payment';
  SELECT pg_get_functiondef(oid) FROM pg_proc WHERE proname = 'sp_record_payment';
  SELECT pg_get_functiondef(oid) FROM pg_proc WHERE proname = 'sp_apply_late_penalty';
  SELECT pg_get_functiondef(oid) FROM pg_proc WHERE proname = 'sp_notify_overdue_bills';

Verify bill-generation trigger (after step 7 — meter reading):
  SELECT id, event_type, message, email_sent FROM notifications
  WHERE event_type = 'BILL_GENERATED' ORDER BY id DESC LIMIT 5;

15. DATABASE BACKUP & RESTORE
================================================================================

--- Backup (already in project) ---
  mkdir backup
  set PGPASSWORD=12345678
  "C:\Program Files\PostgreSQL\18\bin\pg_dump.exe" -h localhost -U postgres -d wasac_db -F p -f backup\wasac_db_backup.sql

  File: backup\wasac_db_backup.sql

--- Restore to fresh database ---
  psql -U postgres -c "DROP DATABASE IF EXISTS wasac_db_restore;"
  psql -U postgres -c "CREATE DATABASE wasac_db_restore;"
  set PGPASSWORD=12345678
  psql -U postgres -d wasac_db_restore -f backup\wasac_db_backup.sql

--- Restore over existing wasac_db (destructive) ---
  psql -U postgres -c "DROP DATABASE wasac_db;"
  psql -U postgres -c "CREATE DATABASE wasac_db;"
  psql -U postgres -d wasac_db -f backup\wasac_db_backup.sql
